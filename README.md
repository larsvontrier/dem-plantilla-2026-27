## Entregas

Cada entrega se marca con una etiqueta (`tarea-01` a `tarea-08` e `informe-final`) y se comunica en el aula virtual con el SHA completo del commit, según la guía de entrega de la UD12.

Este repositorio debe ser privado, con acceso únicamente para su autor o autora y para el docente del módulo.

## Aviso sobre los datos

Los datos de `municipios-energia.csv` son sintéticos: reproducen relaciones documentadas sobre eficiencia energética y vulnerabilidad, pero no son datos reales. Ninguna conclusión obtenida en este repositorio es una afirmación sobre la situación energética de los municipios españoles.
